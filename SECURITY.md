# Security

This repository holds only configuration and documentation: a plugin manifest, a pointer to a remote MCP server, and one skill. It contains no executable code, hooks or scripts.

The MCP server at `https://developmentradio.dev/mcp` is read-only, needs no account, holds no user data and returns only what is already published on developmentradio.dev.

## Reporting a problem

Please report a suspected vulnerability in the plugin, the MCP server or developmentradio.dev privately through GitHub: **Security → Report a vulnerability** on this repository (https://github.com/MasasaDeveloper/development-radio-plugin/security/advisories/new). Please do not open a public issue for a security problem.

Useful details: what you sent, what came back, and why it is a problem. You should get a reply within a week.
